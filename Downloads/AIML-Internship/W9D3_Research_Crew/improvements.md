# W9D3 Research Crew – Improvement Review

## Without Web Search

The first crew used three agents:
- Researcher
- Writer
- Reviewer

The researcher generated information using the local LLM. The writer converted it into an article and the reviewer checked the quality.

## With Web Search

The second crew used the Serper web search tool with the Researcher agent.

This provided access to current online information and real-world examples.

## Improvement Observed

The web-enabled crew produced more current and detailed research.

### Main Improvements
- Access to current web information
- More real-world examples
- Better research depth
- More useful supporting information
- Improved relevance of the final article

## Conclusion

Adding web search improved the research quality because the Researcher could use current information instead of relying only on the local language model.
