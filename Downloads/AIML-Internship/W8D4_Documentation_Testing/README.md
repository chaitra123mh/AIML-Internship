# W8D4: Documentation, Testing & Code Review

## Objective

The objective of W8D4 is to document, test, and review the Haystack-based retrieval system developed during Week 8.

The system uses two retrieval approaches:

- BM25 Retrieval
- Dense Retrieval

The system was tested using 5 PDF documents and 10 questions.
