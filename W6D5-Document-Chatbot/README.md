# W6D5 - Document Chatbot with LangChain

## Objective
Build a simple document chatbot using PDF, Ollama, and LangChain concepts.

## Features
- PDF document loading
- Document context extraction
- Ollama LLM integration
- Question answering
- Local LLM execution

## Technologies
- Python
- PyPDF2
- Ollama
- Llama 3.2 3B

## Result
The PDF was loaded successfully and Ollama generated an answer using the document context.
