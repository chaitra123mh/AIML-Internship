# W8D1 - Production RAG: Evaluation & Optimisation

## Project Overview

This project demonstrates the basic productionisation of a machine
learning API using FastAPI, Docker, GitHub Actions, and MLOps practices.

The API accepts a numeric input and returns a prediction.

## Technologies Used

- Python 3.12
- FastAPI
- Pydantic
- Uvicorn
- Docker
- GitHub Actions
- MLflow
- Ragas
- MLOps
